# 003 - Dva booking moda

**Status:** prihvaceno

## Odluka

Aplikacija podrzava `open_booking` i `fixed_schedule`. Nacin rada definira se postavkom studija, a zajednicki model rezervacija koristi se u oba moda.

## Posljedice

- `open_booking` omogucuje clanu samostalan odabir termina
- `fixed_schedule` koristi trajne dodjele clanova rasporedima
- rezervacije ostaju evidencija konkretnih dolazaka u oba moda
- mobilni prikaz moze prilagoditi akcije bez razdvajanja aplikacije na dva proizvoda
